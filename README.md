# Neovim Configuration

A minimal, personalized Neovim IDE built around native functionality, lightweight plugins, and a clean terminal-based interface.

Designed for **Neovim 0.12.4** on **NixOS + Hyprland + Kitty**, with a focus on Python, Lua, TypeScript, JavaScript, Go, and Nix development.

## Features

- **Minimal interface:** Molokai colorscheme with a transparent background and compositor blur.
- **Animated cursor:** Smooth cursor movement powered by `smear-cursor.nvim`.
- **Native package management:** Uses Neovim's built-in `vim.pack` instead of Lazy or Packer.
- **Syntax highlighting:** Tree-sitter with language-specific parsers.
- **LSP:** Native Neovim LSP with diagnostics, navigation, renaming, and code actions.
- **Autocompletion:** Blink.cmp with minimal completion menus and documentation previews.
- **File explorer:** Nvim-tree positioned on the right, with file and folder icons.
- **Fuzzy finding:** Snacks Picker for files, buffers, commands, and project-wide text search.
- **Statusline:** Lualine with Git branch, file information, diagnostics, and cursor position.
- **Formatting:** Conform.nvim with language-specific formatters.
- **Git integration:** Gitsigns for Git change indicators and hunk operations.
- **Editing utilities:** Mini.pairs and Mini.surround.
- **Custom keybindings:** Simple, predictable keyboard shortcuts.

## Requirements

- Neovim 0.12.4+
- Git
- A terminal with true-color support
- Nerd Font (for file icons)
- Ripgrep (for project-wide search)
- Tree-sitter CLI 0.26.1+
- C compiler (GCC)
- curl and tar
- Language servers and formatters

Transparency and blur are provided by Kitty and Hyprland, not Neovim itself.

## Language Servers

Native Neovim LSP is used with `nvim-lspconfig`.

| Language | Server |
|---|---|
| Lua | `lua_ls` |
| Python | `basedpyright` |
| JavaScript / TypeScript | `ts_ls` |
| Go | `gopls` |
| Nix | `nixd` |

Language-server executables are managed through NixOS rather than Mason.

### Diagnostics

Diagnostics use a minimal presentation:

- Signs in the sign column
- Underlined errors and warnings
- Floating diagnostic windows
- No inline diagnostic text cluttering the editor

## Formatting

Formatting is managed through `conform.nvim`.

| Language | Formatter |
|---|---|
| Python | Ruff |
| Lua | StyLua |
| JavaScript / TypeScript | Prettier |
| React / TSX | Prettier |
| HTML / CSS | Prettier |
| JSON / YAML / Markdown | Prettier |
| Go | gofmt |
| Nix | nixfmt |

To format the current file, press `Space + gf`.

If a configured external formatter is unavailable, Conform can fall back to LSP formatting when supported.

## NixOS Dependencies

Install the relevant packages through your existing NixOS configuration:

```nix
environment.systemPackages = with pkgs; [
  # Editor tools
  git
  ripgrep
  fd

  # Tree-sitter dependencies
  tree-sitter
  gcc
  curl
  gnutar

  # Language servers
  lua-language-server
  basedpyright
  typescript-language-server
  typescript
  gopls
  nixd

  # Formatters
  ruff
  stylua
  prettier
  nixfmt
  go

  # Clipboard
  wl-clipboard
];
```

Add missing packages to the existing package list rather than duplicating `environment.systemPackages`.

The TypeScript language server is available as `typescript-language-server` in current Nixpkgs. The older `nodePackages` namespace has been removed.

## Installation

### 1. Clone the configuration

```bash
git clone <your-repository-url> ~/.config/nvim
```

Replace the placeholder with your repository URL.

### 2. Install system dependencies

Add the required packages to NixOS and rebuild using your normal workflow.

### 3. Launch Neovim

```bash
nvim
```

Neovim's native package manager installs the configured plugins.

### 4. Verify LSP

Open a supported source file and run:

```vim
:checkhealth vim.lsp
```

### 5. Verify Tree-sitter

```vim
:checkhealth nvim-treesitter
```

To inspect the syntax tree of an open source file:

```vim
:InspectTree
```

### 6. Verify formatting

Open a supported source file and run:

```vim
:ConformInfo
```

This displays the available formatters for the current buffer.

## Plugin Management

Plugins are managed through `vim.pack`.

Update plugins:

```vim
:packupdate
```

Review the changes before confirming an update.

The `nvim-pack-lock.json` file records plugin revisions and should be committed to version control for reproducibility.

## Appearance

The visual design uses:

- Molokai syntax highlighting
- Transparent editor backgrounds
- Kitty terminal opacity
- Hyprland background blur
- Smooth cursor animation
- Filetype icons through a Nerd Font
- Flat, minimal statusline
- Single-line popup borders
- No startup dashboard or unnecessary animations

The objective is to preserve a clean editing surface while making IDE functionality available through keyboard shortcuts.

## Design Philosophy

This configuration follows a few simple principles:

1. Use native Neovim features whenever practical.
2. Prefer small, independent plugins over large distributions.
3. Keep plugin configurations in separate Lua modules.
4. Install system tools declaratively through NixOS.
5. Favor keyboard-driven navigation over permanent UI panels.
6. Add features only when they provide a clear improvement to development workflows.

**Minimal by design. Functional by necessity.**
